Settings & Backup

Manage your data, export, and import sessions

Export Backup

Download all your session data as a JSON file. Keep this safe — it's your full backup that can be re-imported at any time, on any device.

Import Backup

Restore from a previously exported sessions.json file. Your existing data will be merged — no duplicates, no data loss.

Danger Zone

Permanently delete all session data. This action cannot be undone. Export a backup first if you want to keep your data.
